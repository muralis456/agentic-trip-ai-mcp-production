# Customer Lifecycle Management Project Knowledge

## Overview
A telecom customer lifecycle management platform designed to support service-provider processes, product/service bundling and customer interactions.

## Architecture
The application follows a layered/3-tier architecture with RESTful backend services, action/controller components, Spring service classes, DTO/form objects and DAO components. Camel routes are used for third-party integrations.

## Engineering responsibilities
Typical work includes requirements analysis, low-level design, REST API implementation, backend business validation, third-party API integration, bug fixing, reusable component identification, unit testing, integration testing and performance-oriented testing.

## Technology themes
Java, Spring, Hibernate, RESTful web services, JUnit, Oracle, MongoDB, JSON, Maven, Git, Tomcat, Guvnor, Jersey and Apache Camel.

## RAG relevance
Useful durable knowledge includes layered architecture, integration patterns, business validation approaches and telecom lifecycle concepts. Customer/account data and credentials must not be indexed.
