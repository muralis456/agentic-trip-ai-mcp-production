# Travel Planning Guide

This project knowledge document contains durable travel-planning guidance for the AgenticTripAI demo.

## Planning a multi-day trip

A practical itinerary should account for arrival and departure time, travel time between areas, opening hours, meal breaks, and a small amount of unplanned time. Avoid scheduling distant attractions back-to-back when transit time is significant.

## Building an itinerary

Group activities by geographic area where possible. Put weather-sensitive outdoor activities on flexible days and keep at least one indoor alternative for destinations with variable weather. The first day should be lighter because travelers may be affected by airport transfers and check-in.

## Budget planning

Separate transport, accommodation, food, activities, local transport and contingency. A contingency buffer helps absorb small price changes and unexpected expenses. The final budget should be based on real-time tool results when available rather than static knowledge-base estimates.

## Important boundary

This knowledge base is not a source of live prices, flight schedules, hotel inventory, weather forecasts, exchange rates or official visa decisions. AgenticTripAI should use its MCP tools or official sources for those current facts.
